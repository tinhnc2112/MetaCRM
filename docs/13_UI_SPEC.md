# UI Specification

## Navigation
Inbox
Customers
Orders
POS
Products
Inventory
Shipments
Reports
Settings

## Inbox
Three columns:
conversation list | chat | customer panel.

Conversation filters:
unread, assigned-to-me, all, page, tag, status.

Customer panel:
identity, phone, address, tags, notes, orders, timeline, create order.

## Order drawer
customer, items, quantity, discount, shipping fee, receiver data, COD total, confirm, create shipment, tracking, timeline.

## Orders
Filters: status, source, staff, date, customer.

## POS
Keyboard-friendly product search/cart.

## Inventory
physical/reserved/available + movement history.

## Reports
Admin-only cost/profit.
